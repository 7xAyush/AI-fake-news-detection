# AI Fake News Detection

## Project Documentation

### Tech Stack
- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express, MongoDB
- **Machine Learning Model:** Scikit-learn, TensorFlow

### Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/7xAyush/AI-fake-news-detection.git
   cd AI-fake-news-detection
   ```
2. Install the frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```
3. Install the backend dependencies:
   ```bash
   cd backend
   npm install
   ```
4. Start the backend server:
   ```bash
   cd backend
   npm start
   ```
5. Start the frontend server:
   ```bash
   cd frontend
   npm start
   ```
   Or equivalently:
   ```bash
   npm run dev
   ```

### ML Model Details
- **Type:** Supervised Learning
- **Algorithms Used:** Logistic Regression, Random Forest
- **Data Sets:** Collected from various news articles labeled as fake or real
- **Evaluation Metrics:** Accuracy, Precision, Recall, F1-Score

### Backend Features
- RESTful API for handling requests and responses
- User authentication and authorization
- Integration with the ML model for predictions
- Database operations using MongoDB

### Frontend Features
- User-friendly interface for data input
- Display of results and predictions
- Responsive design for mobile and desktop views

## Conclusion
This project aims to build a robust system that detects fake news using advanced machine learning techniques and provides a seamless user experience across all platforms.
